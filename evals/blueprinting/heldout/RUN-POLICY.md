# H1 pre-output run policy — declared, not executed or newly authorized

This policy and all H1 inputs/keys freeze together in manifest.json before generation. Separate
source review must first record reviewer identity, snapshot hash, findings and disposition. The
author cannot supply that review. No runs are requested by this authoring task.

For later use within existing authority, run two complete blocks of the same five cases in order
manufacturing, service, finance, presales, rfp. Each block has one first attempt per case per arm:
Blueprinting versus baseline without its/domain instructions, templates or helpers. Block 2 is a
predeclared repeat, not a repair or a retry chosen after a failure. Use fresh independent contexts
per case/arm/block; preserve manufacturing's own stages. Complete both blocks' worker attempts
without revealing judgments or first-block outputs to second-block workers. No key tuning between
blocks. Lock the configured model/mode/reasoning effort, environment, tool capabilities and package
revisions before block 1 and use identical settings throughout; actual model IDs must be recorded
at execution, not invented here. Baseline gets ordinary document tools and exactly the same evidence.

Inherited per-worker ceiling: 75 active minutes, 100 tool calls, no delegation, no paid external
calls/browsing, four distinct topics per stage, stage 0 preparation uncharged. Only controller wait
pauses the clock. No borrowing unused budget. Twenty worker attempts maximum across two blocks
(1,500 active minutes and 2,000 tool calls aggregate ceilings, not targets). Zero automatic retries;
zero repair attempts in this reliability tranche. Any later repair is separately labelled exploratory
and outside this policy. Do not use the shared protocol's optional repair allowance here.

One fixed judge configuration: six H1 calibration calls, one per frozen example, all must meet the
expected verdict and source-grounded reason. Failed calibration blocks acceptance evidence; do not
silently swap judges or retry. For each case/block pair, two fresh absolute single-output judgments
locked first, then two fresh pairwise judgments in reversed order: 40 assessment calls plus six
calibration calls maximum. Per call: 20 active minutes, 30 read-only tool calls, no delegation or
external writes (920 minutes/1,380 calls aggregate ceilings). Use neutral IDs, conceal mappings and
prior judgments, retain substantive formatting and report recognizable skill cues. Pair order for
the first view is Blueprinting first when zero-based case index plus zero-based block index is even,
baseline first when odd; the second view reverses it. Use that same alternation for worker arm
execution order. Keep the mapping controller-private. Preserve both judgments, never pick the
favorable order. Existing original judgments and calibration failures remain in the record.

For each arm/case/block report separate semantic dimensions, critical failures, completion, export
limitations, exact output hashes, actual available time/calls/questions and contamination. Report
pairwise better/worse/tied/inconclusive independently of absolute pass. Compare repeated blocks
descriptively: pass/fail agreement, dimension changes and differing critical findings. Report order
reversals and judge instability; don't average them into wins. Budget exhaustion retains partial
work and fails applicable completion; environment interruptions are blocked, not wins or reruns.

Five variants are five independent engagement designs, each paired with its development archetype,
not a representative random sample. Two repeats are correlated observations of those same five
cases, not ten new independent cases. Eleven stages per block/arm are not new samples. This modest
check can expose instability; it cannot establish statistical reliability, general superiority or
bias-free judging. Do not pool stages or repeats for an inflated sample size, infer population
confidence intervals, or claim significance. No token/provider-dollar telemetry is available here;
report unavailable, not zero. Equal ceilings do not establish equal realized cost or savings.

Owner handoff, native artifact inspection, Review 1 → repair/revalidation → fresh Review 2 and
final value judgment remain outside this unexecuted authoring tranche. Missing integration evidence
stays NOT DEMONSTRATED. Any prospective policy change must be recorded before outputs under its
applicable authority, preserving this version; it does not retroactively become the preregistration.
